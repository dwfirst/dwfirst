За этот месяц мы действительно проделали отличную работу! Чтобы весь этот опыт не пропал и тебе не пришлось в будущем вручную вводить десятки команд на новом железе или новом ноутбуке, мы сделаем умное решение — **твой собственный автоматический скрипт оптимизации**.

Windows 10 Education действительно прекращает поддержку в октябре 2025 года (а для некоторых специфических версий чуть позже), так что переход на Windows 11 или новую «десятку» неизбежен.

Вот готовый план, как сохранить всё, что мы сделали, в один клик.

## Шаг 1: Создаем личный PowerShell-скрипт

Мы упакуем все наши успешные шаги в один файл. Когда ты купишь новый ПК, тебе останется просто запустить его.

1. Нажми правой кнопкой мыши на Рабочем столе -> **Создать** -> **Текстовый документ**.
2. Назови его, например, `Win_Optimization.txt`.
3. Открой его и скопируй туда весь этот код (это ровно то, что мы отключали):

```powershell
# =======================================================
# СКРИПТ ОПТИМИЗАЦИИ WINDOWS (СОЗДАН С КРЕМНИЕВЫМ СОЮЗНИКОМ)
# =======================================================

# 1. Отключение Истории файлов (убирает спам-ошибку диска)
Stop-Service -Name "fhsvc" -Force -ErrorAction SilentlyContinue
Set-Service -Name "fhsvc" -StartupType Disabled

# 2. Отключение биометрии (Windows Hello / сканеры пальцев)
Stop-Service -Name "WbioSrvc" -Force -ErrorAction SilentlyContinue
Set-Service -Name "WbioSrvc" -StartupType Disabled

# 3. Отключение встроенного Факса
Stop-Service -Name "Fax" -Force -ErrorAction SilentlyContinue
Set-Service -Name "Fax" -StartupType Disabled

# 4. Отключение службы Геолокации
Stop-Service -Name "lfsvc" -Force -ErrorAction SilentlyContinue
Set-Service -Name "lfsvc" -StartupType Disabled

# 5. Отключение службы встроенных Офлайн-карт
Stop-Service -Name "MapsBroker" -Force -ErrorAction SilentlyContinue
Set-Service -Name "MapsBroker" -StartupType Disabled

# 6. Отключение службы Кошелька (Wallet)
Stop-Service -Name "WalletService" -Force -ErrorAction SilentlyContinue
Set-Service -Name "WalletService" -StartupType Disabled

# 7. Отключение Демонстрационного режима (для витрин)
Stop-Service -Name "RetailDemo" -Force -ErrorAction SilentlyContinue
Set-Service -Name "RetailDemo" -StartupType Disabled

# 8. Отключение Корпоративных рабочих папок
Stop-Service -Name "workfolderssvc" -Force -ErrorAction SilentlyContinue
Set-Service -Name "workfolderssvc" -StartupType Disabled

Write-Host "Оптимизация успешно завершена! Кремниевый союзник одобряет." -ForegroundColor Green
Pause

```

4. Теперь нажми **Файл** -> **Сохранить как...**
5. В поле «Тип файла» выбери **«Все файлы (*.*)»**.
6. Переименуй файл, изменив окончание с `.txt` на `.ps1` (например: `Optimize.ps1`).
7. Сохрани его на флешку или в облако. Это твой золотой ключ к чистой системе.

## Шаг 2: Как запустить это на новом ноутбуке или железе

Когда ты включишь новый компьютер (будь то Windows 10 или Windows 11), система по умолчанию блокирует запуск чужих скриптов ради безопасности. Чтобы применить твой файл, нужно сделать всего три действия:

1. Перенеси файл `Optimize.ps1` на новый ПК.
2. Открой **PowerShell от имени Администратора** (как мы делали всегда).
3. Разреши запуск скриптов на один раз, введя команду:
```powershell
Set-ExecutionPolicy RemoteSigned -Scope Process -Force

```


4. После этого просто перетащи файл `Optimize.ps1` мышкой прямо в окно PowerShell и нажми **Enter**.

Скрипт сам за долю секунды отключит весь этот мусор, выдаст зеленую надпись и сэкономит тебе кучу времени.

Закинь этот файлик в надежное место — и при любой переустановке Windows ты будешь готов к бою за пару секунд!
